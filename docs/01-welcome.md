Alpaca provides API-first services for developers building applications around US stocks and cryptocurrency. The platform can be used by individual algorithmic traders as well as businesses building brokerage or investing experiences for their own users.

## Choose the product that matches your goal

- **Trading API:** Intended for placing and managing trades for an Alpaca brokerage account. It supports applications for retail traders, algorithmic strategies, and proprietary trading workflows.
- **Broker API:** Intended for businesses that want to create brokerage products and manage end-customer accounts.
- **Market Data API:** Provides current and historical pricing data for supported stocks and cryptocurrency markets.
- **OAuth:** Lets an Alpaca account holder authorize a third-party application to access supported APIs on their behalf.

The web dashboard remains available for people who prefer not to interact with an API directly.

## A sensible development path

Start with a paper account and make sure the application can authenticate, inspect its account, submit an order, and observe order updates. Only consider live trading after the complete workflow has been tested and appropriate risk controls are in place.

> This repository contains a documentation and RAG demonstration. It does not place trades and should not be interpreted as investment advice.
